# 📚 Lessons Learned

This document summarizes the key technical lessons learned from the networking and cybersecurity labs in this repository.

## 📞 FreeBSD + Asterisk VoIP Lab

Through this lab, I learned how to build and configure a VoIP communication system using FreeBSD, Asterisk PBX, and Linphone softphones.

### Key Lessons

- How to install and configure FreeBSD in a virtualized environment
- How to install and manage the Asterisk PBX service
- How SIP/PJSIP extensions register with an Asterisk server
- How internal extension-to-extension calling works
- How voice and video calls use SIP signalling and RTP media
- How conference calling can be configured using ConfBridge
- How PF firewall rules can be used to allow only required VoIP traffic
- How SIP-TLS improves signalling security
- How ZRTP can be used for media encryption
- How voicemail and IVR features improve PBX functionality
- How to troubleshoot VoIP registration, calling, and media issues

### Main Learning Outcome

This lab improved my understanding of VoIP architecture, SIP/PJSIP configuration, FreeBSD administration, firewall rules, secure communication, and practical network troubleshooting.

## 🔥 pfSense Firewall and Network Security Lab

Through this lab, I learned how to build a protected network environment using pfSense, virtual machines, firewall rules, NAT, IDS/IPS monitoring, and controlled security testing.

### Key Lessons

- How to install and configure pfSense in a virtual lab
- How WAN, LAN, and OPT interfaces separate network zones
- How DHCP and DNS services support internal clients
- How firewall rules control allowed and blocked traffic
- How NAT port forwarding works in a lab environment
- How website blocking can be tested using firewall rules and logs
- How DVWA can be used safely for controlled web security testing
- How Snort IDS/IPS detects suspicious traffic
- How SYN flood and port scan detection work in a controlled lab
- How OpenVPN remote access can be prepared using certificates
- How Tailscale subnet routing can provide secure remote access without exposing the firewall directly to the public Internet

### Main Learning Outcome

This lab improved my practical understanding of firewall configuration, network segmentation, NAT, IDS/IPS monitoring, VPN concepts, remote access, and defensive cybersecurity testing.
